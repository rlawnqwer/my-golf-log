MY GOLF LOG v1.2 — 갤럭시 S25용 PWA

파일: index.html, style.css, app.js, sw.js, icon.svg, manifest.webmanifest

설치 안내
1. 이 폴더 전체를 정적 HTTPS 웹 호스팅(예: GitHub Pages)에 배포합니다.
2. 갤럭시 S25의 Chrome에서 배포 URL을 엽니다.
3. Chrome 메뉴(⋮) > 홈 화면에 추가 > 설치를 누릅니다.
4. 설치 뒤 한 번 온라인에서 열면 오프라인 사용을 위한 파일이 캐시됩니다.

중요: zip 파일을 휴대폰에 복사해 열기만 해서는 정식 PWA로 설치되지 않습니다.
웹서버 배포 시 폴더 구조를 그대로 유지해야 합니다. HTTPS 또는 localhost에서 Service Worker 동작.

주요 기능
- 클럽별 연습 평균 캐리, 선택형 총거리/타수, 날짜, 연습장, 스윙/목적, 메모, 레슨 연결
- 연습일별 중앙값/평균/변동/타수 가중 평균(타수 기록만), 클럽별 거리 차이
- 레슨 내용, 느낀 감각, 고정 스윙 포인트
- IndexedDB 로컬 전용 저장
- gzip 압축 전체 JSON 백업 / JSON 복원 / 엑셀용 CSV 내보내기
- 앱 내 백업 알림 (앱 미사용 중 자동 알림은 지원하지 않음)

데이터 주의
- 정적 웹 호스트에는 연습 기록이 전송되지 않습니다. 모든 입력은 휴대폰 브라우저 IndexedDB에 저장됩니다.
- 현재 구현은 앱 열기/저장할 때만 백업 경고를 표시합니다.
- 전체 백업 버튼 클릭은 파일 다운로드 요청이며 실제 보존 성공을 보증하지 않습니다. 다운로드 폴더에서 백업 파일을 확인하세요.
- 휴대폰 분실, Chrome 앱 데이터 삭제, 사이트별 저장소 정리 시 기록을 잃을 수 있습니다. 백업을 PC 등 별도 매체에 옮기세요.
- 클럽 대표 거리의 중앙값은 개별 샷 중앙값이 아니라 각 연습 기록의 평균값을 다시 집계한 중앙값입니다.
- 기타 기능 확장 및 자동 동기화는 미구현.
